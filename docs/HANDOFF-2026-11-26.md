## How to work (what the last session learned)
- Models (owner's rule): building = Opus only where Sonnet failed or the work is hard design; reviews, test fixes,
  recording = Sonnet; scripts for anything measurable. One agent over a panel. Keep your own context small.
- **Usage**: the owner's weekly plan resets Fri 1:59 AM (Pacific). Estimated cost of items 1-6: about 8 to 12 percent of
  one week (Sonnet helper about 160-190k tokens each, roughly 0.7 percent; an Opus build lane about 3 percent). If any
  call says a usage limit was hit, stop starting agents and say where things stand. Never go into paid overage.
- Worktrees: `git worktree add <scratchpad>/wt-x -b <branch> <base>` then `cp -al /home/user/trainingmodecode/node_modules
  <wt>/node_modules` (a symlink breaks Metro). Dev server: `CI=1 EXPO_NO_TELEMETRY=1 npx expo start --web --port 8091 --clear`
  and restart it with `--clear` after every edit (Metro serves stale code otherwise). Chromium is at
  /opt/pw-browsers/chromium (CHROME_PATH). Run photo or smoke scripts in chunks under 9 minutes: a container restart kills
  longer commands (use run_in_background for builds).
- **Smoke test** (scripts/smoke-web.mjs, last CI step, about 60 minutes): `npm run -s build:web` then
  `CHROME_PATH=/opt/pw-browsers/chromium SMOKE_ONLY='<regex of check names>' SMOKE_DEBUG=1 npm run -s smoke:web`. It broke
  three times this week after UI changes (selectors, text, a button whose <style> sat inside it). Run the affected checks
  before pushing: a failed CI run costs an hour.
- **Shipping**: branches: work on the branch your session is given; open the PR into `app` with the GitHub MCP tools
  (load them with ToolSearch), wait for the `checks` job (about 60 minutes; do not poll in a loop: use send_later
  check-ins), merge with a merge commit only when everything is green and `expectedHeadSha` matches. The owner approved
  shipping each item above to everyone. `app` deploys on Netlify.
- Checks that must pass before a push: `npx tsc --noEmit`, eslint on changed files, test:missions, test:qm, test:challenge,
  test:voice, test:clips, test:spoken, voice:coverage --strict (+ the suites the change touches).
- Visual rule: everything fits at 360, 390 and 430 wide, nothing cut or crowded, preview photos before shipping.
- Never touch the live database without the owner's approval; never share the owner's email outside the session.
- Remind the owner in one line of exercise-loops/PENDING.md when loops, exercises or recording come up.
